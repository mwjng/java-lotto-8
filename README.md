# 로또

간단한 로또 발매기를 구현하는 프로그램입니다. 사용자는 구입 금액을 입력하고, 당첨 번호와 보너스 번호를 입력한 뒤에
구매한 로또의 당첨 내역과 수익률을 확인할 수 있습니다.

## 실행 결과

```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능 목록

### 로또 구입 금액 입력

- 사용자로부터 로또 구입 금액을 입력받는다
    - 예외) 숫자가 아니면 예외처리
    - 예외) 1000원 미만인 경우 예외처리
    - 예외) 1000원 단위가 아닌 경우 예외처리
    - 예외가 발생한 경우 에러메시지를 출력하고 다시 입력받는다

### 로또 발행

- 구입금액에 해당하는 만큼 로또를 발행한다
    - 로또 1장의 가격은 1,000원이다
    - 각 로또는 1~45 범위의 중복되지 않는 6개의 숫자로 구성
- 발행한 로또 수량 및 번호를 출력한다
    - 로또 번호는 오름차순으로 정렬하여 출력

### 당첨 번호 입력

- 사용자로부터 당첨 번호를 입력받는다
    - 번호는 쉼표(,)를 기준으로 구분
    - 예외) 숫자가 아니면 예외처리
    - 예외) 숫자의 개수가 6개가 아니면 예외처리
    - 예외) 1보다 작거나 45보다 큰 숫자가 존재하면 예외처리
    - 예외) 중복된 숫자가 존재하면 예외처리
    - 예외가 발생한 경우 에러메시지를 출력하고 다시 입력받는다

### 보너스 번호 입력

- 사용자로부터 보너스 번호를 입력받는다
    - 예외) 숫자가 아니면 예외처리
    - 예외) 1보다 작거나 45보다 크면 예외처리
    - 예외) 당첨 번호와 중복되면 예외처리
    - 예외가 발생한 경우 에러메시지를 출력하고 다시 입력받는다

### 당첨 결과

- 각 로또 번호와 당첨 번호를 비교해서 일치하는 숫자의 개수를 계산한다
- 총 수익률을 계산한다
    - `총 당첨 금액 / 로또 구입 금액 * 100`
    - 수익률은 소수점 둘째 자리에서 반올림한다
- 당첨 내역 및 수익률을 출력하고 프로그램을 종료한다
